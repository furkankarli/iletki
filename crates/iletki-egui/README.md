# iletki-egui

The optional `egui` adapter for the iletki viewport. Use `ViewportPaintCallback` with the re-
exported `egui` and `egui_wgpu` APIs to paint in an existing render pass.

`cargo add iletki-egui`

[API documentation](https://docs.rs/iletki-egui)
