# iletki-wgpu

The framework-agnostic GPU viewport host. It manages offscreen render targets, external render
pass compositing, draw layers, and asynchronous 64-bit picking.

`cargo add iletki-wgpu`

[API documentation](https://docs.rs/iletki-wgpu)
