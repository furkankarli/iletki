# iletki-core

Double-precision viewport math, 2D and 3D cameras, frusta, input and draw contracts, and 64-bit
picking IDs. This crate has no external runtime dependencies.

`cargo add iletki-core`

[API documentation](https://docs.rs/iletki-core)
